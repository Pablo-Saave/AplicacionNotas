# klip

Tareas minimalistas, rápidas y sin conexión. PWA en HTML, CSS y JavaScript puro.

- Secciones → apartados → tareas, guardadas localmente en IndexedDB.
- Paleta: marfil `#FAF7F2`, azul tinta `#1D2B5C`, esmeralda `#00A060`, rosa niebla `#F4E1DE` (solo acento).
- Tipografías: Playfair Display + Arial (Arimo como respaldo), archivos locales en `/fonts`.

Probar en local: `npx serve` o la extensión Live Server (el service worker no funciona abriendo `index.html` con doble clic).
